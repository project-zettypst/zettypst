# zettyp-capture

Capture plans and verification for [ZetTypst](https://github.com/project-zettypst/zettypst), built on [zettyp-host](https://github.com/project-zettypst/zettypst/tree/main/host). Projects provide note templates and file access; [zettypst.nvim](https://github.com/project-zettypst/zettypst.nvim) executes the plans.

```typst
#import "@preview/zettyp-capture:0.1.0" as capture
```
