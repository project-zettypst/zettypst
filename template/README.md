# ZetTypst Grove

A place for connected notes. Built with [ZetTypst](https://github.com/project-zettypst/zettypst) and [Astro](https://astro.build/). [Use this template](https://github.com/project-zettypst/grove/generate) to start.

```sh
pnpm install
pnpm dev
```

Edit `note/welcome.typ` to begin. Register new notes in `.zettypst/source.toml`; customize shared settings in `.zettypst/lib.typ`.

To deploy, select **GitHub Actions** under **Settings → Pages → Source**, then push to `main`. For other hosts, run `pnpm build` and publish `dist/`.
