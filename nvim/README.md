# zettypst.nvim

The official [Neovim](https://github.com/neovim/neovim) plugin for the [ZetTypst](https://github.com/project-zettypst/zettypst) note-taking system, powered by [zettyp-lsp](https://github.com/project-zettypst/zettypst/tree/main/lsp) and requiring [snacks.nvim](https://github.com/folke/snacks.nvim). Supports the latest stable and nightly versions of Neovim. Works out of the box with [zettypst-kickstart](https://github.com/project-zettypst/zettypst/tree/main/kickstart).

```lua
require("zettypst").setup(require("zettypst.presets.kickstart"))
```
