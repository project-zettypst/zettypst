# ZetTypst Capture

The Chrome extension for [zettypst.nvim](../../README.md). Capture web pages and PDFs into your ZetTypst project.

Enable developer mode at `chrome://extensions` and load this directory as an unpacked extension. In Neovim, open your target project and run:

```vim
:Zet capture install-native-host
```

Click **Check native host** in the extension to verify the connection, then capture the current page or PDF.
